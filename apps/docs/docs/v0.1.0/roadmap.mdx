# Product roadmap

The stable v0.1 release establishes the versioned form contract, deterministic compiler, controlled runtime, visual Designer, host adapters, and governed `FormPatch` workflow. It does not claim full JSON Schema, complex-form, collaboration, or form-platform parity.

| Milestone | Product outcome |
| --- | --- |
| v0.1 · current | Contract foundation and embedding model |
| v0.2 | Runtime integrity: closed schema profile, computed rules, async validation, data sources, localization, and incremental performance |
| v0.3 | Complex forms: nested data, repeatable groups, grids, matrices, true wizards, broader fields, and visual rule/integration editors |
| v0.4 | Governance: drafts and releases, history, diff, rollback, approvals, collaboration, offline sync, audit, policy, and migration |
| v1.0 | Stable AI-native workflow across inspect, patch, simulate, test, approve, and publish operations |

The detailed capability ownership, known boundaries, acceptance criteria, non-goals, and release gates are available in the [next roadmap](/next/roadmap) and canonical [ROADMAP.md](https://github.com/A3S-Lab/Form/blob/main/ROADMAP.md).

Planned capabilities are not part of the stable v0.1 contract until their release gates pass.
