A3S Form 将“表单文档”作为可版本化、可校验、可确定性编译的产品契约。设计器只负责编辑契约，运行时负责渲染和交互，宿主负责数据源、动作、权限与持久化。

</div>

## 现在可以做什么

- 在 Playground 中管理多个表单、在线新建并自动保存到浏览器 `localStorage`。
- 使用常用字段、分组、分栏、标签页和可重复区块完成复杂布局。
- 注册业务自定义节点，并为它提供独立配置面板和运行态组件。
- 将无 UI 的编译器与状态机嵌入 a3s-cloud，或使用 React、Vue、Web Component 适配器。
- 通过 Rust WASM 加速热路径，同时在不支持 WebAssembly 时保持相同结果。

## 五分钟开始

```bash
bun install
bun run dev
```

浏览器打开终端显示的地址，先从“我的表单”进入示例，也可以直接创建一个本地表单。
