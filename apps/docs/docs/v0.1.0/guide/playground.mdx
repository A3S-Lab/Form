# Playground

Playground 采用与 A3S Office 子组件一致的工作台与编辑器视觉语言，默认界面为中文。

## 多表单工作台

首页展示浏览器内的全部表单，支持：

- 按标题或说明搜索；
- 查看字段数、修订号和最后更新时间；
- 从空白画布在线创建表单；
- 在表单列表和设计器之间切换；
- 刷新页面后恢复表单。

数据使用版本化键 `a3s-form-workspace:v1` 存入 `localStorage`。旧的单表单数据会在首次读取时迁移，损坏或受限的存储会安全回退到当前会话。

## 设计器布局

编辑器包含组件目录、结构树、中央画布、属性/校验配置面板以及设计/预览切换。字段和容器都支持拖放；分栏和标签页等容器仍可继续接收子节点。
