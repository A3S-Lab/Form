# 快速开始

## 安装依赖

```bash
bun install
```

## 启动在线设计器

```bash
bun run dev
```

启动后首先显示中文“我的表单”工作台。示例表单和新建表单都保存在当前浏览器，不要求登录，也不会上传本地内容。

## 在 React 中渲染

```tsx
import { assertCompiled } from '@a3s-lab/form/core';
import { FormRenderer } from '@a3s-lab/form/react';
import '@a3s-lab/form/styles.css';

export function ApplicationForm({ document, value, onChange }) {
  const plan = assertCompiled(document);
  return <FormRenderer plan={plan} value={value} onChange={onChange} />;
}
```

这份样式已经包含 A3S Form 使用的 `@a3s-lab/ui@0.2.0` 组件契约，无需重复导入 A3S UI。

## 质量检查

```bash
bun run check
```

项目对语句、分支、函数和行覆盖率都设置了 `95%` 门槛。
