# Embed a workflow node form

A3S Form can sit inside a Dify-like node settings panel without taking over the workflow product. The host owns the node value and persistence. A3S Form owns compilation, validation, and rendering.

## Pin the form release

Each node stores a configuration-mode `FormRef`:

```ts
const form = {
  uri: 'a3s://forms/workflow/llm',
  revision: 7,
  digest: 'sha256:…',
  mode: 'configuration',
};
```

`revision` and `digest` prevent a later form release from changing an existing node silently.

The resolved plan also carries `schemaProfile: "a3s.dev/form-schema-profile/1"`. A host that does not support that profile must fail closed before rendering the node settings.

## Keep the value controlled

```tsx
import { FormRenderer } from '@a3s-lab/form/react';
import {
  createWorkflowNodeConfiguration,
  validateWorkflowNodeConfiguration,
  verifyPinnedForm,
} from '@a3s-lab/form/workflow';
import { FORM_LOCALE_CATALOG_API_VERSION } from '@a3s-lab/form/core';
import '@a3s-lab/form/styles.css';

const pinned = verifyPinnedForm(document, form);
if (!pinned.ok) throw new Error(pinned.message);

const configuration = createWorkflowNodeConfiguration({
  nodeType: 'llm',
  nodeId,
  form,
  value,
  locale,
  readOnly: !canEdit,
});

const save = async () => {
  const result = validateWorkflowNodeConfiguration(pinned.document, configuration);
  if (!result.ok) {
    setErrors(result.errors);
    return;
  }
  await saveNode({ ...configuration, value: result.value });
};

<FormRenderer
  plan={pinned.plan}
  value={value}
  errors={errors}
  hostAdapter={hostAdapter}
  locale={locale}
  localeCatalog={{
    apiVersion: FORM_LOCALE_CATALOG_API_VERSION,
    messages: { selectPlaceholder: 'Choose a model' },
  }}
  readOnly={!canEdit}
  onChange={setValue}
  onAction={save}
/>;
```

The host still decides whether the actor can edit, where the value is stored, which secrets a data source may use, and whether an action may run.

Locale overrides are host configuration and are not stored in the workflow node value or form document. The compiled plan also records field subscriptions, so editing one node setting does not redraw or refetch unrelated settings. Pagination and field callbacks still receive the newest complete controlled value.

## Keep repeater identity outside node configuration

An object-array parameter can use a `repeater` node with child fields. The host receives the same plain array through `onChange`; A3S Form does not add a hidden row key.

If an external state store recreates row objects, derive identity from a business property:

```tsx
const hostAdapter = {
  identifyRepeaterItem({ node, item }) {
    if (node.id !== 'routes' || !item || typeof item !== 'object' || Array.isArray(item)) {
      return undefined;
    }
    return typeof item.route === 'string' ? item.route : undefined;
  },
};
```

Declare `itemKey` only when the item schema intentionally contains a required string identifier. Read the [repeatable field-group guide](/next/guide/repeatable-field-groups) for nested paths, limits, and current row-scoped rule restrictions.

## CSS stays inside the form

The Form stylesheet does not contain Tailwind preflight, `:root` tokens, or unscoped element resets. A package check enforces a 120 KB raw / 20 KB gzip budget and rejects host-global selectors.

The type-checked reference component lives in [`examples/dify-like-workflow-node.tsx`](https://github.com/A3S-Lab/Form/blob/main/examples/dify-like-workflow-node.tsx).
